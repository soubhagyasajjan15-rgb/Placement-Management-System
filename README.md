# Placement Management System

## Description
The Placement Management System is a Python-based application that helps manage student placement records. It allows users to add, view, search, update, and delete student information. The system also manages company details and placement drives.

## Features
- Admin Login
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Add Company
- View Companies
- Search Company
- Delete Company
- Add Placement Drive
- View Placement Drives
- Eligible Students
- Dashboard
- Export Student Report to CSV

## Technologies Used
- Python
- JSON
- CSV
